# Tamagotchi Meets 한국어 육성가이드 — 사용 안내

BERRYMURE 쇼케이스 템플릿의 레트로 창(윈도우) 디자인을 그대로 살려서 만든
**다마고치 미츠(たまごっちみーつ) 한국어 팬 위키**입니다.
일본어를 몰라도 캐릭터·진화·결혼·아이템·마을 정보를 한국어로 확인하고,
게임 속 일본어 메뉴를 번역 사전에서 바로 찾아볼 수 있어요.

## ⚠️ 꼭 읽어주세요 (중요)

- 이 사이트는 **비공식 팬 사이트**예요. BANDAI/공식 다마고치 미츠와는 관련이 없습니다.
- 캐릭터 이름처럼 널리 알려진 정보는 참고해 넣었지만, **필요 행복도·케어미스 횟수·유전자 확률 같은 세부 수치는 예시(placeholder) 값**입니다.
  실제 최신 공략 데이터를 확인한 뒤 아래 방법으로 채워 넣어 사용해주세요.
- 저작권 보호를 위해 실제 게임 스크린샷은 포함하지 않았어요. 필요하면 직접 플레이하며 찍은 스크린샷을
  `assets/images/` 폴더에 넣고 각 페이지 코드에서 이미지 태그로 연결해 사용하세요.

## 폴더 구조

```
index.html          홈(허브) — 전체 메뉴, 오늘의 추천
characters.html      캐릭터 도감 (검색/필터/즐겨찾기/체크리스트)
growth.html          성장조건 · 진화 트리
marriage.html        결혼 가이드
genetics.html        유전자 조합 계산기 (예시 시뮬레이션)
items.html           아이템 DB (음식/장난감/액세서리/배경, ?filter=food 등 지원)
towns.html           마을 가이드
translate.html       일본어 ↔ 한국어 번역 사전
faq.html             자주 묻는 질문
admin.html           관리자 페이지 (로컬 데이터 편집)

assets/css/base.css   원본 템플릿 스타일(재사용)
assets/css/guide.css  가이드 사이트 전용 추가 스타일 (다크모드 포함)
assets/js/data.js     ⭐ 모든 콘텐츠 데이터 (캐릭터/아이템/마을/사전/성장조건)
assets/js/common.js   공통 내비게이션 · 다크모드 · 즐겨찾기 · 토스트
assets/js/*.js        각 페이지 전용 로직
manifest.webmanifest  PWA 설치용 매니페스트
sw.js                 오프라인 캐시용 서비스워커
```

## 데이터를 실제 게임 정보로 채우는 방법

**방법 1. 관리자 페이지 사용 (추천, 코드 몰라도 OK)**
1. `admin.html`을 브라우저로 열어요.
2. 캐릭터 / 아이템 / 마을 / 번역 탭에서 원하는 데이터를 추가·삭제해요. (이 브라우저에만 저장됩니다)
3. 다 채운 뒤 **"JSON으로 내보내기"** 버튼을 눌러 파일을 받아요.
4. 그 JSON 내용을 참고해 `assets/js/data.js`의 `DEFAULT_DATA` 안 배열들을 실제 데이터로 바꿔주세요.
   (이렇게 해야 다른 사람이 접속해도 같은 데이터가 보여요. localStorage는 접속한 사람 각자의 브라우저에만 저장돼요.)

**방법 2. 코드 직접 수정**
`assets/js/data.js` 파일을 열어 `characters`, `items`, `towns`, `dictionary`, `growthStages`, `marriage`
배열/객체에 원하는 만큼 항목을 추가하면 사이트 전체(도감, 검색, 번역사전 등)에 자동으로 반영돼요.

## 새 캐릭터 이미지(사진) 넣기

지금은 이모지(🌟 등)로 캐릭터를 표시해요. 실제 캐릭터 이미지를 넣고 싶다면:
1. 이미지 파일을 `assets/images/` 폴더에 넣어요.
2. `data.js`의 캐릭터 항목에 `img` 대신 `imgSrc: "assets/images/파일명.png"` 같은 필드를 추가하고,
   `characters.js`의 카드/모달 렌더링 부분에서 이모지 대신 `<img>` 태그를 쓰도록 살짝 수정해주세요.

## 배포하기

- Netlify: 이 폴더를 그대로 드래그 앤 드롭하면 `netlify.toml` 설정으로 바로 배포돼요.
- GitHub Pages / Vercel 등 정적 호스팅도 동일하게 폴더만 올리면 동작해요.
- PWA로 설치하려면 **https로 배포**해야 서비스워커(`sw.js`)가 정상 동작해요.
